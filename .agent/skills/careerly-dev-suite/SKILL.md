# Careerly Complete Development Multi-Agent Suite

Master skill that activates and orchestrates the complete suite of specialized skills for the Careerly platform.

## Included Specialized Skills
1. **`careerly-orchestrator`** — Task decomposition, routing, and file lock management.
2. **`careerly-architecture`** — System design, REST API contracts, and package governance.
3. **`careerly-frontend`** — React 19 views, Lucide icons, glassmorphism CSS, and theme switching.
4. **`careerly-backend`** — Express 5 routes, middlewares, rate limiters, and request validators.
5. **`careerly-discovery`** — Opportunity V4 search orchestrator, Serper adapter, and scrapers.
6. **`careerly-ai`** — Google Gemini integrations, CV Studio ATS tailoring, Copilot, and Coach.
7. **`careerly-database`** — SQLite schemas, indexes, better-sqlite3, and Supabase sync.
8. **`careerly-security`** — 14-category security framework, SSRF, IDOR, and penetration tests.
9. **`careerly-qa`** — Full automated regression test suites (Build, Discovery, Adversarial, Penetration, Evidence).
10. **`careerly-devops`** — Render deployment configuration, Vite optimization, and environment templates.
11. **`careerly-code-review`** — Static analysis, Oxlint verification, and diff auditing.

## Execution Rules
- Always preserve completed security phases and existing Opportunity V4 discovery behavior.
- Always execute `careerly-qa` to verify all 5 test suites before marking tasks complete.
